# Capabilities

> Generated by `npm run gen:capabilities`. Do not edit by hand.

### `bluetooth` — Bluetooth LE

BLE central: scan, native device picker, connect, list services, read/write characteristics, subscribe to notifications (heart-rate straps, sensors, beacons, custom hardware).

Limits:

- Central role only: the phone can't act as a peripheral.
- No classic Bluetooth (audio, serial SPP).
- Values are DataView: decode bytes yourself.

```tsx
const ble = useConnector('bluetooth')
const device = await ble.requestDevice({ services: ['180d'] })
await ble.connect(device.deviceId)
const stop = await ble.subscribe(device.deviceId, '180d', '2a37', (v) => setBpm(v.getUint8(1)))
```

Full typed API: `src/core/connectors/bluetooth/api.ts`. Mock fixtures: fake heart-rate strap 'Mock HR Strap' + beacon.

### `camera` — Camera and photo picker

Take a photo with the native camera or pick one or more from the photo library.

Limits:

- Photos only, no video.
- Cancelling rejects with UserCancelledError.
- photo.uri goes straight into vlm without base64.

```tsx
const camera = useConnector('camera')
const photo = await camera.takePhoto({ maxSize: 1280 })
<img src={photo.webPath} />
```

Full typed API: `src/core/connectors/camera/api.ts`. Mock fixtures: window.__mocks.camera = { image, fail }.

### `geolocation` — Geolocation

GPS / network position, one-shot or streamed (with speed and heading while moving), plus a distance helper.

Limits:

- Foreground only: no background tracking.
- No maps or geocoding (no backend); show coordinates or draw your own.

```tsx
const geo = useConnector('geolocation')
const here = await geo.getPosition()
useSubscription(() => geo.watchPosition(setPosition), [])
```

Full typed API: `src/core/connectors/geolocation/api.ts`. Mock fixtures: window.__mocks.geolocation = { latitude, longitude, fail }.

### `haptics` — Haptics

Taptic Engine (iOS) / vibrator (Android) feedback: impact, success/warning/error pattern, selection tick, vibrate.

Limits:

- No custom patterns on iOS.

```tsx
const haptics = useConnector('haptics')
await haptics.notify('success')
```

Full typed API: `src/core/connectors/haptics/api.ts`. Mock fixtures: no fixtures; uses navigator.vibrate when present.

### `llm` — On-device LLM (OS model)

Text LLM built into the OS: Apple Intelligence (iOS 26+) or Gemini Nano (Android). No download for the app, works offline, multi-turn via sessionId.

Limits:

- Text only, no images (use vlm).
- No token streaming: the whole answer arrives at once.
- Android caps output at 256 tokens: ask for short answers.
- Only on supported devices: check availability() / ensureReady() and show a fallback.

```tsx
const llm = useConnector('llm')
await llm.ensureReady()
const answer = await llm.ask('Summarise: …', { instructions: 'One sentence.' })
```

Full typed API: `src/core/connectors/llm/api.ts`. Mock fixtures: window.__mocks.llm = { reply, availability, fail }.

### `motion` — Motion sensors

Accelerometer, gyroscope, tilt and compass heading as streams. Works on plain-http pages (native backend).

Limits:

- Foreground only.
- High rate (~50–60 Hz): throttle before setting React state.

```tsx
const motion = useConnector('motion')
useSubscription(() => motion.watchOrientation((o) => setHeading(o.heading)), [])
```

Full typed API: `src/core/connectors/motion/api.ts`. Mock fixtures: synthetic sway stream, no fixtures.

### `neuralTts` — Natural voice (Kokoro neural TTS)

Chatbot-quality voices on the device (Kokoro 82M). Speaks streamed LLM output sentence by sentence while it is still generating.

Limits:

- One-time ~370 MB download, then offline. Ask before downloading (use the models recipe).
- Languages: US/UK English, Spanish, French, Hindi, Italian, Brazilian Portuguese, Chinese. Others (Czech, German, Japanese …) need tts.

```tsx
const voice = useConnector('neuralTts')
await voice.prepare(setProgress)
await voice.speak('Hi! How can I help?', { voice: 'af_heart' })
const stream = voice.createSpeechStream()
await vlm.ask(q, {}, (t) => stream.push(t)); await stream.end()
```

Full typed API: `src/core/connectors/neuralTts/api.ts`. Mock fixtures: window.__mocks.neuralTts = { downloaded, fail }; speaks through the browser voice.

### `notifications` — Local notifications

Show a notification now or schedule one for later (reminders, timers). Tap events come back to the app.

Limits:

- Local only: no push, no server.
- Ids are shared with other apps in the shell: cancel only ids you created.

```tsx
const notifications = useConnector('notifications')
await notifications.notify({ title: 'Break time', at: new Date(Date.now() + 25 * 60_000) })
```

Full typed API: `src/core/connectors/notifications/api.ts`. Mock fixtures: logs to console; window.__mocks.notifications.sent.

### `qr` — QR / barcode scanner

Native full-screen scanner for QR codes and, with anyFormat, every common barcode (EAN, UPC, Code 128, DataMatrix, PDF417 …).

Limits:

- One code per scan; the scanner closes after the first hit.
- Closing the scanner rejects with UserCancelledError.

```tsx
const qr = useConnector('qr')
const { text, format } = await qr.scan({ instructions: 'Scan the label', anyFormat: true })
```

Full typed API: `src/core/connectors/qr/api.ts`. Mock fixtures: window.__mocks.qr = { text, format, fail }.

### `speech` — Speech to text

OS speech recognizer with a live transcript. Many languages including Czech and German.

Limits:

- Listens until the user pauses (one utterance); call again for the next.
- May need network on some Android devices.
- Ask for permission with ensurePermission() first, on a user tap.

```tsx
const speech = useConnector('speech')
const text = await speech.listen({ language: 'en-US' }, setLiveText)
```

Full typed API: `src/core/connectors/speech/api.ts`. Mock fixtures: window.__mocks.speech = { transcript, fail }.

### `storage` — Persistent storage (core, always present)

Key/value storage that survives app restarts. Modules use it through useStoredState / useModuleStorage (auto-prefixed per app and module), and blobs (photos) through useBlobStore (IndexedDB).

Limits:

- Strings only at the raw level; JSON helpers on top.
- Keep values small (settings, lists). Photos and large data go to useBlobStore.
- Core uses it, never pruned.

```tsx
const [notes, setNotes] = useStoredState<string[]>('notes', [])
const store = useModuleStorage()
await store.setJSON('last', { at: Date.now() })
```

Full typed API: `src/core/connectors/storage/api.ts`. Mock fixtures: browser localStorage (prefix mock:).

### `tts` — System text-to-speech

Speaks text with the OS voices. Every language the OS has (Czech, German, Japanese …), no download.

Limits:

- Sounds more robotic than neuralTts.
- Some Android voices need network: prefer voices with offline: true.
- Best iOS voices (Enhanced/Premium) must be downloaded by the user in Settings.

```tsx
const tts = useConnector('tts')
await tts.speak('Dobrý den', { lang: 'cs-CZ' })
```

Full typed API: `src/core/connectors/tts/api.ts`. Mock fixtures: browser speechSynthesis.

### `vlm` — Vision-language model (Qwen3-VL)

On-device multimodal LLM: ask questions about photos (describe, OCR, count, compare, read labels) or plain text chat, with token streaming. Runs fully offline after a one-time download.

Limits:

- One-time download: 2B ≈ 1.6 GB, 4B ≈ 3 GB (4B needs 8 GB+ RAM). Always show progress and ask before downloading (use the models recipe).
- Must be loaded into memory before asking (a few seconds).
- Slower than cloud models: keep maxTokens small (100–300) and images ≤ 1280 px.
- Stateless: send the whole conversation each time.

```tsx
const vlm = useConnector('vlm')
if (!(await vlm.isDownloaded('qwen3-vl-2b'))) await vlm.download('qwen3-vl-2b', setProgress)
await vlm.load('qwen3-vl-2b')
const { text } = await vlm.ask('What does the sign say?', { images: [photo.uri], maxTokens: 200 }, (t) => append(t))
```

Full typed API: `src/core/connectors/vlm/api.ts`. Mock fixtures: window.__mocks.vlm = { reply, downloaded, fail }.

## Recipes

Ready-made hooks/components combining connectors. Import from `@core/recipes/<id>`.

### `ai` — AI chat (OS model)

useAiChat() keeps a multi-turn conversation with the on-device OS LLM (messages, busy, error, send, reset); useAiStatus() tells whether the device has one.

Exports: `useAiChat`, `useAiStatus`. Uses connectors: `llm`.

```tsx
import { useAiChat } from '@core/recipes/ai'
const chat = useAiChat({ instructions: 'You are a cooking assistant. Short answers.' })
await chat.send('What can I make with eggs?')
```

### `models` — Model downloads

useModelDownload() tracks and downloads on-demand models with progress; <ModelGate> asks before downloading and renders its children once the model is ready.

Exports: `useModelDownload`, `ModelGate`, `formatBytes`. Uses connectors: none.

```tsx
import { ModelGate } from '@core/recipes/models'
<ModelGate download={vision.model} name="Qwen3-VL 2B" sizeBytes={1.6e9}>…</ModelGate>
```

### `scan` — Scanner with history

useScanner(): QR/barcode scan with haptic feedback and a persisted, per-module history list.

Exports: `useScanner`. Uses connectors: `qr`, `haptics`.

```tsx
import { useScanner } from '@core/recipes/scan'
const scanner = useScanner({ anyFormat: true })
<AsyncButton onClick={scanner.scan}>Scan</AsyncButton>
```

### `vision` — Photo Q&A (vision model)

useVision(): take or pick a photo, ask about it, stream the answer from on-device Qwen3-VL. Includes model download state for <ModelGate>.

Exports: `useVision`. Uses connectors: `camera`, `vlm`.

```tsx
import { useVision } from '@core/recipes/vision'
import { ModelGate } from '@core/recipes/models'
const vision = useVision()
<ModelGate download={vision.model} {...vision.modelInfo}>
  <AsyncButton onClick={vision.takePhoto}>Photo</AsyncButton>
  <AsyncButton onClick={() => vision.ask('Read the label')}>Ask</AsyncButton>
  <StreamingText text={vision.answer} streaming={vision.streaming} />
</ModelGate>
```

### `voice` — Voice in/out

useVoice() (neuralTts optional at runtime): listen with a live transcript, speak with the natural Kokoro voice (falls back to the system voice for other languages or before download), speechStream() to speak streamed LLM output.

Exports: `useVoice`. Uses connectors: `speech`, `neuralTts`, `tts`.

```tsx
import { useVoice } from '@core/recipes/voice'
const voice = useVoice({ language: 'en-US' })
const question = await voice.listen()
await voice.speak(answer)
```

## Core hooks (`@core`)

| Hook | Purpose |
| --- | --- |
| `useConnector(id)` | Typed device API (real in ProtoShell, mock in browser). |
| `useCapability(id)` | `true` if the capability is usable now. |
| `useSubscription(subscribe, deps, { enabled })` | Run a streaming subscription while mounted (sensors, GPS, BLE). |
| `useStoredState(key, initial)` | `useState` persisted per module. |
| `useModuleStorage()` | Namespaced key/value store (`get/set/getJSON/setJSON/keys/clear`). |
| `useBlobStore()` | IndexedDB blobs (photos); `toBlob(photo.webPath)`. |
| `persistStorage(moduleId)` | Storage for zustand `persist`. |
| `useModuleSettings()` | `[values, update]` of the module `settings` schema. |
| `useNav()` | `toPage(key)`, `toRoute(path)` (module routes), `back()`. |
| `useRouteParams()` | Params of a module route. |
| `useEmit()` / `useEvent(name, handler)` | Typed events between modules. |
| `useFlag(name)` | Read a feature flag. |
| `usePlatform(s => s.mode)` | `'shell'` or `'mock'`. |
| `toast.success/error/info(msg)` | Feedback messages. |
| `appConfig` | App id, name, version. |

Errors from connectors: `UserCancelledError` (ignore), `PermissionDeniedError`, `CapabilityUnavailableError`, `DeviceUnsupportedError`, `TimeoutError`, `CoreError`.
