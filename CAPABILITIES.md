# Capabilities

> Generated by `npm run gen:capabilities`. Do not edit by hand.

What an app built on this template can do on the phone. Every connector works in the browser too, with a mock.

## Connectors

Use in a block: `const api = useConnector('<id>')` (from `@core`). Declare required ones in `requires.capabilities` of `defineModule`, optional ones in `optional.capabilities` and check `useCapability('<id>')`.

| id | What | In shell |
| --- | --- | --- |
| `storage` | Persistent storage | yes |

### `storage` — Persistent storage (core, always present)

Key/value storage that survives app restarts. Modules use it through useStoredState / useModuleStorage (auto-prefixed per app and module), and blobs (photos) through useBlobStore (IndexedDB).

Limits:

- Strings only at the raw level; JSON helpers on top.
- Keep values small (settings, lists). Photos and large data go to useBlobStore.
- Core uses it, never pruned.

```tsx
const [notes, setNotes] = useStoredState<string[]>('notes', [])
const store = useModuleStorage()
await store.setJSON('last', { at: Date.now() })
```

Full typed API: `src/core/connectors/storage/api.ts`. Mock fixtures: browser localStorage (prefix mock:).

## Core hooks (`@core`)

| Hook | Purpose |
| --- | --- |
| `useConnector(id)` | Typed device API (real in ProtoShell, mock in browser). |
| `useCapability(id)` | `true` if the capability is usable now. |
| `useSubscription(subscribe, deps, { enabled })` | Run a streaming subscription while mounted (sensors, GPS, BLE). |
| `useStoredState(key, initial)` | `useState` persisted per module. |
| `useModuleStorage()` | Namespaced key/value store (`get/set/getJSON/setJSON/keys/clear`). |
| `useBlobStore()` | IndexedDB blobs (photos); `toBlob(photo.webPath)`. |
| `persistStorage(moduleId)` | Storage for zustand `persist`. |
| `useModuleSettings()` | `[values, update]` of the module `settings` schema. |
| `useNav()` | `toPage(key)`, `toRoute(path)` (module routes), `back()`. |
| `useRouteParams()` | Params of a module route. |
| `useEmit()` / `useEvent(name, handler)` | Typed events between modules. |
| `useFlag(name)` | Read a feature flag. |
| `usePlatform(s => s.mode)` | `'shell'` or `'mock'`. |
| `toast.success/error/info(msg)` | Feedback messages. |
| `appConfig` | App id, name, version. |

Errors from connectors: `UserCancelledError` (ignore), `PermissionDeniedError`, `CapabilityUnavailableError`, `DeviceUnsupportedError`, `TimeoutError`, `CoreError`.
